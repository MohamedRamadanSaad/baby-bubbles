# فقاعات

لعبة أندرويد للأطفال الرضع: كرات ملونة تطفو وتنفجر باللمس بأصوات موسيقية، داخل إطار مقفل لا يخرج منه إلا الأب.

## التثبيت على الهاتف

كل رفع على الفرع الرئيسي يبني ملف تثبيت جديدًا وينشره في صفحة الإصدارات. أحدث نسخة دائمًا باسم:

```
baby-bubbles.apk
```

النسخ الجديدة تُثبَّت فوق القديمة مباشرة لأنها موقّعة بنفس مفتاح التطوير.

## مفتاح الأب

اضغط زري رفع الصوت وخفضه معًا ثلاث ثوانٍ، ثم أجب عن السؤال الحسابي.

## البناء محليًا

```
gradle :app:assembleDebug
```
